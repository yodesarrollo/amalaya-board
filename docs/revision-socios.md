# Amalaya · revisión con socios · 8 de octubre de 2026

Entrada para revisar el modelo: `explorar.html?ligero=1`. Conserva la página,
los recorridos y el tablero existentes. La entrada principal ofrece «Explorar
Amalaya en 3D» sin requerir iniciar sesión para este contenido ya público.
El acceso a los datos privados del board conserva sus permisos.

Cuadras 1 y 8: cinco etapas cerradas visualmente y sus comparaciones publicadas.
La siguiente cuadra de trabajo sigue siendo 9/C20. Este cierre de publicación
no aprueba otras cuadras ni cambia las geometrías.

En la vista Territorio, la falta de contexto gráfico o una carga superior a
15 segundos abre el modelo ligero dentro del mismo portal. No se construye
la escena detallada si el navegador no puede crear un contexto WebGL.

El visor 360 conserva sus fotografías e identificadores. Si WebGL no arranca,
un respaldo Canvas 2D permite girar, acercar y cambiar de punto sin pantalla
negra. Los mensajes del padre conservan ruta, punto y rumbo; las respuestas
asíncronas antiguas no reemplazan la fotografía actual. Los renders «después»
solo aparecen si existe una imagen; no se inventa una propuesta.
La vista ligera no sustituye un recorrido a pie: este requiere WebGL; el
botón Ver edificios conserva una salida útil cuando no está disponible.

Comprobaciones: suite del repositorio, verificación de publicación, build,
proyección panorámica cardinal y arranque sin WebGL. La revisión visual pública
cubre entrada, modelo ligero, selección de edificio, navegación 360, enlace
compartido y fichas de cuadra. Las sesiones privadas no se simulan ni se alteran.
